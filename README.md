**Лисквиз** — сервис интерактивных экспресс-викторин внутри **Сферума** на платформе **MAX**, который за 30 секунд генерирует проверочные викторины по темам Федеральных рабочих программ (ФРП) с помощью ИИ, проводит синхронную живую игру в классе с защитой от списывания и формирует наглядную карту пробелов с рекомендациями для учителя.

## ✨ Ключевые возможности платформы

1. ⚡ **Генерация викторины за 30 секунд**:
   - По темам рубрикатора ФРП (1–11 классы) через GigaChat API / YandexGPT.
   - По фотографии разворота школьного учебника или доски (сквозной Vision + RapidOCR CPU пайплайн).
   - Офлайн-банк канонических школьных тем с автоматической защитой от вузовских терминов.
2. 🛡️ **Античит-система нового поколения (ML 2.0)**:
   - 4 уникальных изоморфных варианта (перемешивание кнопок и геометрических фигур).
   - Effort-Moderated Scoring: отсечение кликов быстрее порога чтения $T_{floor} = 1.2 + 0.22 \times N_{words}$ сек.
   - Тихий аудит сворачивания вкладок и переключения окон без остановки игры.
3. 📊 **Честный диагностический отчёт учителя (Class Gap Report)**:
   - 100% реальная телеметрия (никаких искусственных заглушек).
   - Распределение по 3 тирам сложности (Базовый, Средний, Босс-раунд).
   - Выявление первопричин пробелов через Knowledge DAG (направленный граф учебных пререквизитов).
4. 🌿 **Мета-игра «Классная Роща 2.0» (Retention & Командный дух)**:
   - Совместный полив древа класса по закону минимума Либиха (необходим вклад каждого ученика).
   - Этичная гача знаний с гарантированным выпадением карточек (Soft-Pity 10, Hard-Pity 30, без лудомании).
   - Звуковой ландшафт: разделение «Проектор учителя» (макро-звук) vs «Смартфон ученика» (тактильный вибро-отклик).
5. 🔒 **Соответствие 152-ФЗ (Zero-PII Architecture)**:
   - Полное отсутствие сбора и хранения персональных данных школьников (ФИО, телефоны, email).
   - Обезличенные криптографические идентификаторы (`pid_...`).

## 🚀 Инструкция по сборке и запуску через Docker

В соответствии с требованиями номинации «Продвинутая разработка» поддержаны два официальных варианта развертывания: **единый production-контейнер** и **мультиконтейнерный Docker Compose**.

### Вариант А: Единый легковесный Docker-образ (Рекомендуется для проверки)

Образ собирается в два этапа (multi-stage):
1. **Этап 1 (Node.js 20 Alpine)** компилирует TypeScript и оптимизирует ассеты React SPA в бандл `dist/`.
2. **Этап 2 (Python 3.12-slim)** устанавливает зависимости ML-рантайма, копирует бэкенд и собранный SPA, запуская высокопроизводительный ASGI-сервер Uvicorn на порту 8000.

#### 1. Сборка Docker-образа:
```bash
docker build -t lisquiz:latest .
```

#### 2. Запуск контейнера через командную строку:
```bash
docker run -d \
  -p 8000:8000 \
  --name lisquiz_app \
  --env-file .env \
  --restart unless-stopped \
  lisquiz:latest
```
*(Если файл `.env` ещё не создан, скопируйте шаблон: `cp .env.example .env`).*

#### 3. Просмотр логов контейнера:
```bash
docker logs -f lisquiz_app
```

#### 4. Остановка контейнера:
```bash
docker stop lisquiz_app && docker rm lisquiz_app
```

### Вариант Б: Мультиконтейнерная архитектура (Docker Compose)

Запуск полного стека (FastAPI бэкенд, Nginx фронтенд, PostgreSQL 16, Redis 7):

```bash
# Сборка и фоновый запуск всех сервисов
docker compose up --build -d

# Проверка статуса контейнеров
docker compose ps

# Остановка сервисов с сохранением томов данных
docker compose down
```

## 🩺 Примеры проверки работы сервиса через командную строку (CLI)

После старта контейнера откройте терминал и выполните проверочные команды:

### 1. Проверка работоспособности сервиса (Health Check):
```bash
curl -i http://localhost:8000/api/health
```
*Ожидаемый ответ:* `HTTP/1.1 200 OK`, JSON с состоянием БД, Redis и провайдера LLM.

### 2. Запрос тем из рубрикатора ФРП (Математика, 7 класс):
```bash
curl -s "http://localhost:8000/api/quiz/bank/topics?subject=Математика&grade=7"
```

### 3. Проверка доступных школьных классов для учеников:
```bash
curl -s http://localhost:8000/api/classes
```
*Возвращает список классов (например, 7А класс с кодом `7A-OWL`).*

### 4. Проверка состояния мета-игры «Классная Роща 2.0»:
```bash
curl -s http://localhost:8000/api/grove/0d44b68f-6721-4d58-917d-c2a271c5017a
```
*Возвращает уровень Древа, баланс ресурсов (вода, солнце, почва) по закону Либиха.*

### 5. Проверка отдачи собранного веб-интерфейса MAX SPA:
```bash
curl -I http://localhost:8000/
```
*Возвращает `HTTP/1.1 200 OK` и отдаёт скомпилированный `index.html`.*

## 🤖 Интеграция с платформой Сферум / MAX

### 1. Переменные окружения (.env)
Для подключения бота и мини-приложения заполните параметры в файле `.env`:
```env
# Токен бота, полученный от чат-бота «Идея фикс»
MAX_BOT_TOKEN=your_max_bot_token_here

# Идентификатор и секрет мини-приложения в консоли dev.max.ru
MAX_APP_ID=your_max_app_id
MAX_APP_SECRET=your_max_app_secret

# Режим генерации вопросов: 'mock' (офлайн-банк без API ключей) или 'gigachat'
LLM_PROVIDER=mock
GIGACHAT_CREDENTIALS=your_gigachat_credentials
```

### 2. Команды чат-бота в MAX
- `/start` — Приветствие лисёнка Спринта, кнопки быстрого запуска мини-приложения (вход для ученика или учителя).
- `/quiz <PIN>` — Мгновенное подключение к активной классной викторине по 6-значному PIN-коду.
- `/grove` — Переход в «Классную Рощу 2.0»: полив древа, сбор желудей и просмотр карточек знаний.
- `/class <CODE>` — Присоединение к классу по инвайт-коду учителя (например `/class 7A-OWL`).

### 3. Эндпоинт входящего вебхука бота:
Вебхук настраивается на URL:
`https://<ваш_хост_или_туннель>/api/max/webhook`

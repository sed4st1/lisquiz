# Lisquiz — графические ассеты MVP

Стиль: книжная 2D-мультяшная иллюстрация, мягкие цвета и плоские формы.

## Содержимое
- `grove_bg_clean.png`, `quiz_bg_clean.png` — непрозрачные фоны 1080×1920 (9:16).
- `tree_stage1.png` … `tree_stage4.png` — отдельные стадии дерева с альфа-каналом.
- `sprint_idle.png`, `sprint_watering.png`, `sprint_thinking.png`, `sprint_celebrate.png` — позы Спринта с альфа-каналом.
- `acorn_gold.png`, `acorn_empty.png`, `sign_wooden.png` — элементы UI с альфа-каналом, без текста.
- `icon_sprout.svg`, `icon_calc.svg`, `icon_timer.svg` — редактируемые векторные иконки.

## Примечание
PNG-ассеты вырезаны из общей иллюстративной таблицы. Альфа-канал восстановлен удалением светлой шахматной подложки по границе объекта; перед продакшеном стоит визуально проверить тонкие края и при необходимости подправить их в графическом редакторе. Фоны подготовлены без встроенных карточек, кнопок, таймеров и текста.

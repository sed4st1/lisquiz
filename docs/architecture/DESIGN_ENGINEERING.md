# Дизайн-инженерия интерфейсов: стандарт генерации и устранение машинных шаблонов (Anti-AI-Slop)

Данный документ фиксирует архитектурный стандарт фронтенд-разработки образовательной платформы «ЛисКвиз». Он определяет правила детерминированной генерации веб-интерфейсов для автономных кодинг-агентов (Antigravity, Claude Code, Cursor), исключая визуальную конвергенцию («AI Slop») и гарантируя уровень студийной дизайн-инженерии.

---

## 1. Феноменология дефектов машинной генерации (AI Slop)

Большие языковые модели при отсутствии жестких ограничений демонстрируют выраженную стилистическую конвергенцию, воспроизводя пять типовых деструктивных кластеров:

| Измерение интерфейса | Характерный дефект генерации (AI Slop) | Стандарт дизайн-инженерии «ЛисКвиз» |
| :--- | :--- | :--- |
| **Колористика** | Случайные Tailwind-классы (`bg-indigo-600`), фиолетовые/синие линейные градиенты | Семантические CSS-токены в пространстве **OKLCH** с жестким удержанием единой цветовой температуры нейтралей |
| **Пространственная глубина** | Хаотичные тени (`shadow-2xl`), декоративное стекло (`backdrop-blur-md`) | Микротекстуры (SVG noise/woodgrain), фоновые субпиксельные сетки, полупрозрачные границы (`border-border/60`), физический 3D-клик |
| **Шрифтовой стек** | Немодифицированные Inter, Roboto, Arial; акцентирование слов цветом/курсивом | Geist, Manrope, Geist Mono; длина строки строго до 75–80 символов; обязательные табличные цифры `tabular-nums` |
| **Плотность компоновки** | Низкая информационная плотность, пустой whitespace («SaaS Card Kit») | Швейцарская сетка, структурированные Bento-лейауты, компактное размещение данных |
| **Микродинамика** | Разрозненный `fade-in-up` на каждом блоке, медленные переходы | Скоординированный вход сцены, быстрый отклик на действия пользователя (140–180 мс) |
| **Компонентная база** | Ручная верстка составных диалогов через `<div>` без ARIA-ролей | Безголовые примитивы доступности (Radix UI, React Aria, Base UI) |

## 2. Отрицательные эвристики (Prohibited Patterns)

Агенты обязаны соблюдать жесткие запреты:
1. **Запретные градиенты**: никаких линейных градиентов из индиго/фиолетового в циан, никаких градиентных заливок текста.
2. **Шаблонные цветовые схемы**: запрещены палитры «Cream & Terracotta» (#F4F1EA + засечки + глина) и «Acid Neon» (глубокий черный с ядовито-зеленым).
3. **SaaS Card Kit**: запрещена монотонная сетка из одинаковых карточек с размытыми тенями низкой плотности.
4. **Декоративный AI-хром**:
   - Никаких трекинговых заглавных микро-меток (`tracking-widest uppercase text-xs`).
   - Никаких метаданных через средние точки (`A · B · C`).
   - Никаких обязательных стрелок (`→` или `->`) на обычных кнопках и ссылках.
   - Никакого акцентирования отдельных слов в заголовках курсивом или другим цветом.
5. **Типографика**: запрещен дефолтный немодифицированный Inter/Arial без ручной настройки трекинга и высоты строки.

## 3. Математическая модель цвета в пространстве OKLCH

Использование цветового пространства OKLCH гарантирует постоянство воспринимаемой светлоты при смене светлой и темной тем без грязи и паразитных оттенков:

```css
@layer base {
  :root {
    --radius: 0.75rem;
    /* Теплая лесная гамма под маскота Лисквиз */
    --background: oklch(0.99 0.005 85);
    --foreground: oklch(0.18 0.025 145);
    --card: oklch(1 0 0);
    --card-foreground: oklch(0.18 0.025 145);
    --primary: oklch(0.68 0.20 48);          /* Лисий янтарь (Fox Orange) */
    --primary-foreground: oklch(0.99 0 0);
    --secondary: oklch(0.94 0.02 145);
    --secondary-foreground: oklch(0.20 0.03 145);
    --accent: oklch(0.72 0.17 148);           /* Изумрудный мох */
    --accent-foreground: oklch(0.99 0 0);
    --gold: oklch(0.82 0.16 85);              /* Янтарное солнце */
    --destructive: oklch(0.57 0.22 27);
    --border: oklch(0.88 0.015 145);
    --ring: oklch(0.68 0.20 48);
  }

  .dark {
    --background: oklch(0.16 0.025 145);      /* Глубокая ночная хвоя */
    --foreground: oklch(0.98 0.005 85);
    --card: oklch(0.22 0.035 140);
    --card-foreground: oklch(0.98 0.005 85);
    --primary: oklch(0.72 0.21 48);          /* Светящийся лисий янтарь */
    --primary-foreground: oklch(0.12 0.02 145);
    --secondary: oklch(0.26 0.03 145);
    --secondary-foreground: oklch(0.98 0 0);
    --accent: oklch(0.65 0.16 148);           /* Ночной изумруд */
    --accent-foreground: oklch(0.99 0 0);
    --gold: oklch(0.80 0.16 85);
    --destructive: oklch(0.48 0.18 27);
    --border: oklch(0.28 0.025 145);
    --ring: oklch(0.72 0.21 48);
  }
}
```

## 4. Архитектура интеграции реестров компонентов (Model Context Protocol)

Вместо синтезирования сложной интерактивной логики с нуля агент использует проверенные библиотеки через MCP-провайдеры:

```json
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    },
    "origin-ui": {
      "command": "npx",
      "args": ["--yes", "github:kelvinchng/origin-ui-mcp"]
    },
    "21st": {
      "url": "https://21st.dev/api/mcp",
      "headers": {
        "x-api-key": "ENV_21ST_API_KEY"
      }
    }
  }
}
```

- **shadcn MCP**: доступные базовые примитивы на основе Radix UI (Dialog, DropdownMenu, Tooltip, Slider).
- **Origin UI MCP**: комплексные элементы форм, временные диапазоны, селекторы.
- **21st MCP (Magic MCP)**: микро-взаимодействия, физика частиц и визуальные текстуры.

## 5. Барьеры типизации компилятора (`tsconfig.json`)

Для предотвращения дефектов при обращении к несуществующим полям структур или коллекций:

```json
{
  "compilerOptions": {
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "moduleResolution": "bundler",
    "jsx": "react-jsx"
  }
}
```

Флаг `noUncheckedIndexedAccess` типизирует элемент массива как `T | undefined`, обязывая реализовывать явные защитные проверки и заглушки состояний загрузки.

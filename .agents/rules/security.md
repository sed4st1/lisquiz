# Security & Anti-Leak Rules (Lisquiz ECC)

## Защита конфиденциальности и секретов
- НИКОГДА не коммитить API-ключи, токены доступа или client_secret.
- Все ключи (GigaChat, MAX) хранятся ТОЛЬКО в `backend/.env` (файл строго в `.gitignore`).
- Проверять `git status` перед коммитом: файлы `.env` и базы `.db` не должны попадать в индекс.

## Защита от инъекций
- Все SQL-запросы к SQLite должны быть строго параметризованными: `cursor.execute("SELECT ... WHERE id = ?", (item_id,))`.
- Конкатенация строк в SQL (`f"SELECT ... WHERE id = '{item_id}'"`) категорически запрещена.
- Имена учеников санитизируются перед отображением на экранах лидерборда и проекторе.

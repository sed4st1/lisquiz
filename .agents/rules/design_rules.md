# Дизайн-система Лисквиз: Duolingo + Telegram

1. **Telegram-style навигация (Floating Bottom Dock):**
   - Закруглённая парящая капсула внизу экрана (`border-radius: 26px`, отступы по бокам, размытие стекла `backdrop-filter: blur(20px)`).
   - Каждая иконка вкладки расположена внутри круглого контейнера (44x44px).
   - В неактивном состоянии: спокойный тёмный круг `rgba(255, 255, 255, 0.06)`, иконка `#7E8B9B`.
   - В активном состоянии: неоновое кольцо (`border: 2px solid #10B981`), мягкое зелёное свечение (`box-shadow: 0 0 16px rgba(16, 185, 129, 0.45)`), зелёный текст `#10B981`, и светящаяся метка-чёрточка сверху активной кнопки.
   - Иконки: Домой (Home), Роща (Росток / Sprout), Рейтинг (Корона / Crown), Статистика (Столбцы / BarChart2).

2. **Duolingo-стиль плашек и карточек (Высокий контраст и 3D-тактильность):**
   - Никаких блёклых полупрозрачных плашек, из-за которых текст сливается с фоном!
   - Плашки должны быть плотными (solid opaque) цветами `#182544` / `#151F36` со 100% непрозрачностью на фоне, чтобы текст всегда читался идеально.
   - Фирменный скос Duolingo снизу: `border: 2px solid #253557; border-bottom: 4px solid #253557; border-radius: 20px;` (или `box-shadow: 0 4px 0 #253557;`).
   - Акцентные карточки (как Стрик в Duolingo): яркая плашка `#FF9600` со скосом `#D97706` и белыми крупными цифрами.

3. **Тактильные 3D-кнопки в стиле Duolingo:**
   - Кнопки имеют объемный нижний край: `box-shadow: 0 4px 0 #B85000` (для оранжевых) или `0 4px 0 #15803D` (для зеленых).
   - При нажатии: смещение `transform: translateY(2px)` и уменьшение тени `box-shadow: 0 2px 0 ...`.

4. **Высококонтрастная типографика:**
   - Заголовки: чисто белый `#FFFFFF`, насыщенный `font-weight: 800-900`.
   - Подписи и вспомогательный текст: светлые контрастные оттенки `#E2E8F0` / `#CBD5E1`. Запрещено использовать тёмно-серый текст на тёмном фоне.

5. **Никаких точек и слешей между словами:**
   - Никаких `•` и `/` в названиях, статусах и бейджах.

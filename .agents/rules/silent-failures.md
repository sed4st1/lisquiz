# Silent Failure Hunter (Lisquiz ECC)

## Запрещенные паттерны
- Категорически запрещены пустые `except Exception: pass` или `.catch(() => {})`.
- Запрещено возвращать пустые структуры (`[]`, `{}` или `None`) при ошибке, если это маскирует сбой.
- Ошибки должны снабжаться контекстом: `class_id`, `student_id`, `item_id`.

## Требования к надежности
- При сбоях в реальном времени (сессия викторины, расчет очков, генерация вопросов) логировать через `logger.error(..., exc_info=True)`.
- Использовать понятные HTTP-статусы с деталями для клиента (FastAPI `HTTPException(status_code=..., detail=...)`).
- Транзакции базы данных оборачивать в `with conn:`, чтобы исключить частичные записи при сбоях.
